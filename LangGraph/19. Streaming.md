Streaming in LangGraph delivers execution events as they happen rather than waiting for the entire graph to reach END. It operates at two levels: graph-level streaming (emitting node transitions, state changes, or step completions) and token-level streaming (streaming individual words as an LLM generates them).
How Streaming Works: The Core Modes
LangGraph controls streaming output via the stream_mode parameter in .stream() (or .astream()).
| Mode | What It Emits | Primary Use Case |
|---|---|---|
| "values" | Full state snapshot after every node completes execution. | Tracking total graph progress or refreshing full UI state. |
| "updates" | Only the specific dictionary/diff returned by each node. | Step-by-step progress bars, logging, tracing node origins. |
| "messages" | Tokens and chunks produced by LLMs and tools inside nodes. | Real-time chatbot typing animations in conversational UIs. |
| "custom" | Explicit payloads sent mid-node via  StreamWriter. | Custom progress indicators (e.g., "Downloading file 3/10"). |
Code Examples
1. Streaming Node Updates (stream_mode="updates")
Useful when you want to show which node is executing and see what each node contributed to the state:
inputs = {"messages": [("user", "Analyze the latest sales report")]}

for event in graph.stream(inputs, stream_mode="updates"):
    for node_name, node_output in event.items():
        print(f"Finished node: {node_name}")
        print(f"Output diff: {node_output}\n")

2. Streaming LLM Tokens (stream_mode="messages")
To achieve standard typewriter/streaming text output in chat applications, stream using "messages":
inputs = {"messages": [("user", "Explain quantum computing briefly")]}

# Emits message chunks (AIMessageChunk) token-by-token
for message_chunk, metadata in graph.stream(inputs, stream_mode="messages"):
    if message_chunk.content:
        print(message_chunk.content, end="", flush=True)

3. Combining Modes
You can stream both step-level updates and token-level output simultaneously by passing a list:
for mode, payload in graph.stream(inputs, stream_mode=["updates", "messages"]):
    if mode == "messages":
        chunk, meta = payload
        print(chunk.content, end="", flush=True)
    elif mode == "updates":
        print(f"\n[Node transition: {list(payload.keys())[0]}]")

When to Use Streaming
 * User-Facing Interfaces (Chatbots & Web UIs): Prevents the interface from feeling frozen while long LLM generations or multi-step tool calls finish.
 * Long-Running or Multi-Agent Workflows: When agents execute sequential or cyclical reasoning loops, streaming step updates lets users know which sub-agent is active (e.g., "Researcher is searching Google", "Coder is compiling").
 * Observability and Live Monitoring: Streaming updates directly to logs or monitoring dashboards (e.g., Datadog, LangSmith) provides visibility into agent progress before termination.
 * Early Cancellation: If a user sees an agent heading down the wrong branch, streaming allows the client to abort execution without waiting for completion.
