To leverage the Skills feature across [GitHub Copilot](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/add-skills) and [Claude Code](https://github.com/travisvn/awesome-claude-skills), you write structured Markdown files (SKILL.md or skill.md) containing context-specific guidelines, workflows, or scripts and save them in designated folders within your project or user directory. [1, 2, 3] 
Because both AI engines support the Agent Skills open standard, they can share the exact same definitions seamlessly, ensuring consistent coding patterns, automated compliance, and reproducible workflows across your team. [3, 4, 5] 
------------------------------
## 📂 How to Structure a Skill Directory
Skills can be applied locally for your machine or pushed to a Git repository so your entire development team can use them. [2, 6] 
## Project-Specific Skills (Scoped to a Repository)
Place your skills into one of the following root directories. Tools like [GitHub Copilot](https://github.com/copilot) (in Agent Mode) and [Claude Code](https://claude.com/product/claude-code) will automatically detect them: [3, 4, 6] 

* 
* .github/skills/ (Best choice if primarily using Copilot)
* .claude/skills/ (Best choice if primarily using Claude Code)
* .agents/skills/ (Generic cross-compatible folder) [3, 6] 
* 

## Personal Skills (Scoped Across All Workspaces)
To make a skill universally available across your machine, save it to your home directory: [2] 

* 
* ~/.code.claude/skills/
* ~/.config/github-copilot/skills/
* 

Folder Layout Example:

my-project/
├── .github/
│   └── skills/
│       └── spring-boot-crud/
│           ├── SKILL.md          <-- Core instructions & frontmatter
│           ├── template.java      <-- Optional script/resource file
│           └── payload-mock.json  <-- Optional reference fixture

------------------------------
## 📝 Writing a SKILL.md File
Every skill relies on Markdown structured with YAML frontmatter at the top. The frontmatter allows Copilot and Claude to read the skill’s intent and trigger it automatically based on your prompt. [2, 7, 8] 
Create a file named SKILL.md inside your subfolder using this baseline structure: [1] 

---name: spring-boot-crud
description: Use this skill to scaffold Java Spring Boot REST controllers following enterprise design rules.
triggers:
  - "create a new controller"
  - "add a crud endpoint"
  - "scaffold spring boot api"
---# Enterprise Spring Boot REST Scaffolding## Core Guidelines* Always use a constructor-based dependency injection.* Never use @Autowired field injection.* Include Pagination, Sorting, and Filtering on all GET endpoints by default.
## Expected Directory LayoutEnsure the generated classes strictly follow this architecture:
- `com.company.project.controller`
- `com.company.project.service`
- `com.company.project.repository`
## Reference Example```java
@RestController
@RequestMapping("/api/v1/resources")
public class ResourceController {
    private final ResourceService service;

    public ResourceController(ResourceService service) {
        this.service = service;
    }
}
```

## ⚡ Executing and Orchestrating Skills
Once your directory and files are configured, you can call them implicitly or explicitly.
## 1. Implicit / Automatic Triggering
You do not need to call the skill by its full path. When you issue a prompt in [GitHub Copilot Agent Mode](https://docs.github.com/en/copilot/concepts/agents/cloud-agent/about-cloud-agent) or Claude Code such as "Scaffold a new Spring Boot API for products", the AI scans the available skills' descriptions and triggers, matching your prompt to the exact spring-boot-crud rulebook automatically. [2, 4, 8] 
## 2. Explicit Triggering
To force the agent to use a specific standard, invoke it directly by its named trigger: [2] 

"Use the spring-boot-crud skill to build a books management backend."

## 3. Advanced Automations (Executable Scripts)
Skills can do more than provide text context—they can execute tasks. If you place automated shell scripts (e.g., a python script to parse artifacts or run specialized lints) inside the skill folder, you can instruct the AI inside the SKILL.md text to locate and execute those local assets dynamically. [1, 5] 
------------------------------
## 🛠️ Prerequisites & Setup Verification

   1. VS Code Settings: In your settings, search for Copilot Agent Mode and verify that "Use Agent Skills" is checked. [4, 5] 
   2. Environment Dependency: If your custom skill recipes execute underlying local tools (like Node generators or Docker instances), ensure the respective runtimes are active in your machine's environment path. [7] 
   3. Advanced APIs: For deep systemic capabilities (like real-time database queries or infrastructure lookups), consider coupling your custom Skills alongside the [Model Context Protocol (MCP)](https://mcpservers.org/agent-skills/author/github) supported by both platforms. [8, 9]
