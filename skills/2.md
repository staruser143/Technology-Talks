## 1. Zero-Config Microservice & API Scaffolding
The Problem: Every time you start a new microservice, you waste hours setting up boilerplate code, environment configurations, Dockerfiles, and logging middleware to match company standards.
How a Skill Helps: A scaffolding skill acts as a living template. It automatically structures the service, hooks up standard endpoints, and configures the environment based on a single natural language command.
## 📝 scaffold-fastapi-service/SKILL.md

---name: scaffold-fastapi-service
description: Scaffolds an enterprise-ready FastAPI microservice with pre-configured health checks, Docker setup, and logging.
triggers:
  - "create new fastapi microservice"
  - "spin up backend api"
---# FastAPI Microservice Blueprint## Layout Rules- Generate an `app/main.py` entrypoint.
- Include a `/healthz` route that tests database connections.
- Put dependencies in `requirements.txt`.
## Infrastructure AssetsAlways generate this exact `Dockerfile` in the root:```dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```


* Development Impact: You type: "Create a new FastAPI microservice for user notifications." The agent builds the folder structure, inserts the boilerplate, writes the health checks, and drops in a production-ready Dockerfile instantly.

## 2. Auto-Generating End-to-End Testing Suites
The Problem: Writing unit and integration tests is time-consuming. Developers often rush them, leading to poor test coverage, broken mocks, or missed edge cases.
How a Skill Helps: A testing skill reads your newly written code, automatically understands the framework requirements, mocks external network calls, and writes the test assertions following your exact codebase patterns.
## 📝 write-playwright-tests/SKILL.md

---name: write-playwright-tests
description: Automatically generates end-to-end integration tests using Playwright and TypeScript.
triggers:
  - "write e2e tests for this page"
  - "add playwright tests"
---# Playwright Test Standards## Core Rules- Always use `page.getByRole()` or `page.getByTestId()` for selecting elements. Do not use raw CSS classes.
- Every test must use `test.step()` blocks to document the user flow.- Include an explicit check for visible error banners if form submissions fail.


* Development Impact: Open a frontend form component and tell the agent: "Add Playwright tests for this page." The AI injects high-quality assertions, follows the exact locator patterns specified, and writes comprehensive tests without you having to hunt for the latest documentation syntax.

The Problem: Writing Kubernetes manifests, Helm charts, or CI/CD pipelines (like [GitHub Actions](https://docs.github.com/actions)) manually often leads to syntax errors, misconfigured resource limits, or broken rolling deployment strategies.
How a Skill Helps: A deployment skill instantly outputs deployment definitions tailored precisely to your application’s resource demands and architecture patterns.
## 📝 k8s-canary-deploy/SKILL.md

---name: k8s-canary-deploy
description: Generates Kubernetes deployment and service manifests configured for automated canary rollouts.
triggers:
  - "generate deployment manifests"
  - "create k8s config for release"
---# Kubernetes Deployment Blueprints## Rules- Define resource limits explicitly: `cpu: 200m`, `memory: 512Mi`.- Include standard annotations for Prometheus metrics scraping on port 8080.
- Setup a `RollingUpdate` strategy with `maxSurge: 25%` and `maxUnavailable: 0`.


* Deployment Impact: You prompt: "Generate deployment manifests for our new shopping cart service." The agent creates valid YAML configurations, applies your precise enterprise resource caps, and formats the rollout mechanics correctly on the first try.

## 4. Interactive Pre-Flight Deployment Audits
The Problem: Pushing bad secrets, unoptimized code, or missing database migrations breaks production environments and leads to stressful, manual rollbacks.
How a Skill Helps: This skill acts as a smart gateway, running automated diagnostic scripts locally or auditing the codebase before any code hits the remote repository.
## 📝 pre-flight-audit/SKILL.md

---name: pre-flight-audit
description: Audits the workspace for environment security leaks, unlinked migrations, and critical errors before deployment.
triggers:
  - "audit this project for release"
  - "run pre-flight deployment check"
---# Pre-Flight Deployment Checklist## Execution Protocol1. Scan all active source files to confirm no plain-text strings match API keys, passwords, or secret flags.
2. Verify that if any new database models were introduced in this branch, a corresponding file exists in the `/migrations` folder.
3. Automatically run local linting commands (`npm run lint` or `black .`) and report failures.


* Deployment Impact: Before merging a branch, run: "Run pre-flight deployment check." The agent actively combs your changes, checks for security leaks, runs tools in your workspace terminal, and tells you exactly what needs to be fixed before pushing.
